## 改动清单

1. 修正R对glm的vcovCL默认值错误注释，所有相关模型显式使用HC1、cadjust=TRUE；Python显式指定use_correction=True、use_t=False，样条Wald也使用正态分布。
2. R主模型与样条使用glm.control(epsilon=1e-12,maxit=200)。默认glm停止精度使SE有约1.2×10⁻⁶偏差；收紧后与Python数值符合。没有发现必须修正的R语法错误；主要问题属于默认选项、依赖及协议实现。
3. 两边输出primary_precision.csv、trend_precision.csv；执行样条时另输出spline_precision.csv。
4. Python缺失年份保持缺失，不误编码到早期。两边A(d)删除声明重叠者，模拟中正确删除WS0110，保留WS0105。
5. 按协议新增把缺失时长放到最短/最长类别的比例输出；原最小/最大天数连续模型作为额外情景保留。R空类别事件数置零，趋势检验保留非空类别原分值，避免tapply的NA破坏检验。
6. 等待期间扭转仅用Yes/No可判定结局作分母，另报缺失人数；比较报告类别时识别至少3例且consecutive=Yes的系列。缺失consecutive不默认为连续系列。
7. 补充独立读取辅助模块compare_extraction.py（行1字段，行4起数据，结局映射），替代缺失依赖；模拟生成器独立建最小字段工作簿，移除缺失构建工具及/tmp路径。辅助模块不替代真实提取工作簿的全部质控工具。
8. R记录混合模型奇异性/收敛诊断；增加样条节点重复检查，异常时明确停止而非输出无效Wald检验。

## 使用方法与验证范围

将analysis_main.R、analysis_crosscheck.py、make_synthetic_workbook.py和compare_extraction.py放同目录。Python需要openpyxl、numpy、pandas、scipy、statsmodels；R需要readxl、sandwich、lmtest、lme4。

```text
python make_synthetic_workbook.py
Rscript analysis_main.R synthetic_consensus.xlsx r_output
python analysis_crosscheck.py synthetic_consensus.xlsx --out python_output
python verify.py
```

本次环境：R 4.5.2 (ucrt)，readxl 1.6.0，sandwich 3.1-3，lmtest 0.9-40，lme4 2.0-6，Python statsmodels 0.14.6。R sessionInfo完整记录在r_output/results.txt与r_spline_output/results.txt。包提示部分以R 4.5.3构建，且C.UTF-8区域设置启动警告；运行退出码为0，所列核对通过，但不等于已验证所有机器与数据情况。中文云盘路径使R安装位置及包库无法正常解析，本次在英文临时路径运行，结果复制回交付目录；正式运行建议使用英文路径或先验证UTF-8路径兼容。

本核对证明所列模拟情景的一致性，不证明真实数据模型适宜或全部协议输出已完备。协议的全面描述统计、缺失时长者与已报时长者的完整特征对比、按固定术式汇总术后失败仍未完整实现；真实数据正式分析前应补齐这些描述表，并先完成单位/范围/日期/重复/结局依据质控。当前脚本不处理分离的惩罚回归替代推断、极少聚类的可靠小样本推断或所有稀疏亚组，失败或不可估计须保留，不应通过改变预设规则追求显著。
